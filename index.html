Doom Legacy Launcher 2.0 Released!

Features:

  • Integrated Server Browser
  • Double click Join and automatically download PWADs
  • Auto Download Doom Legacy and its Common resource files in the Updates tab
  • Auto Download Shareware IWADs in the Updates tab if needed
  • Launch and Join the game with (some but not all) Doom Legacy features
  • Integrated but limited IRC chat

Requirements:

  • Windows 10/11 with .NET Framework 4.8
  • Doom Legacy and at least 1 IWAD
  • Minimum hardware: Dual-core CPU, 1GB RAM, Direct3D-capable GPU
  • Internet or LAN connection for multiplayer - Open Port 5029 UDP for hosting over the net.
