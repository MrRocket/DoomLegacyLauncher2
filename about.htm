Doom Legacy Launcher 2 Created by: Mr.Rocket

A modern Windows launcher built for the Doom Legacy source engine, designed to make setting up, hosting, and joining games as simple as possible.

ABOUT:
Doom Legacy Launcher 2 handles engine setup, IWAD/PWAD management, network hosting and joining, IWAD/addon integrity verification, and more — all wrapped in an interface inspired by the classic Doom Legacy website look.
